タイピングのもり サイトマップ・ページ一覧

ストーリーマップの5つの行動（あそびをはじめる → ことばをうつ → けっかをみる → ごほうびをあつめる → もっとうまくなる）を、ページに落とし込んだものです。画面の文字は子どもが読めるよう、ひらがな中心にします。

v1.0 +3 ページ ＋ モーダル1
v2.0 ページ追加なし（既存ページを拡張）
追加 +1 ページ（モード別：F-29〜F-32）

全ページ共通ナビゲーション

ヘッダー（大きなアイコン＋ひらがな）
🌳 タイピングのもり
🗺 ステージ v1.0📖 ずかん v1.0

左のロゴでホームへ。MVP ではロゴだけ。おうちのひと向けページはフッターの小さいリンク（子どもが迷い込まない位置）。

キーボード操作（マウスなしで遊べる）

ホーム：Space であそぶ
あそび中：Esc でやめる v1.0
けっか：Enter でもういっかい

あそび中はヘッダーを隠し、ことばとキャラクターだけにして集中できるようにする。

サイトマップ（最大2層）

  • ホーム（もりの入口）MVP
    / キャラクターのあいさつ、さいこうきろく、大きな「あそぶ」ボタン
    • あそぶMVP
      /play ことばを1文字ずつ判定。合うと緑、まちがいは赤。タイマーとキャラの反応
      • けっかMVP
        /result ★1〜3、はやさ・せいかくさ、しんきろく！、まちがえやすかった もじ
        • シールゲット！v1.0
          （モーダル：ページではない） ★の数に応じて新しいシールをもらう演出
    • ステージえらびv1.0
      /stages Lv1〜3 とタイムアタック。★3 で次がひらく。ステージごとのきろく
    • ずかんv1.0
      /stickers あつめたシールの一覧（まだのものはシルエット）
    • きろく追加B
      /records チャレンジ モードのときだけヘッダーに出す。最高記録・★・はやさのグラフ
    • おうちの方へv1.0
      /parents 練習の記録、音のオン/オフ、全データの削除（v2.0 ではやさのグラフ）

※ v2.0 の「とっくんステージ」は /play?stage=weak、「えいたんごモード」は /play?stage=english として、あそぶページを使い回します。M-01 のモーダルは 3層目に見えますが、ページではないので階層には数えません。
※ いちばん最初に コース（🧒 子ども／🎒 学生（中学・高校）／💼 社会人）を選びます。コースで 背景（森・教室・会社の社内）、問題の難しさ、画面の言葉、アプリ名が変わります（F-33〜F-36）。
※ モード（🌱 はじめて＝A／🔥 チャレンジ＝B）は、はじめて開いたときにホームで選び、ヘッダーのバッジから選びなおせます。モードによって ★の基準・あそぶ画面・ステージの数・「きろく」ページの有無が変わります。

設計チェック

✓階層が3層以内

最も深いのは「ホーム → あそぶ → けっか」の2層。

✓重要な機能が2クリック以内

あそぶはホームで Space キー1回（0クリック）。けっかは打ち終わると自動で表示。ステージ・ずかんはヘッダーから1クリック。

✓ナビゲーションの一貫性

全ページ同じヘッダー。開始・中断・もういっかいがすべてキーボードで操作できる。

✓メンタルモデルに沿った構造

子ども向けゲームで一般的な「スタート → あそぶ → けっか → もういっかい」の流れ。保護者向けの管理機能は子どもの動線から外している。
