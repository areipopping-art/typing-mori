## 1. プロジェクト概要

### 背景
- 【要確認】小学校でタブレットやパソコンを使う授業が増え、ローマ字入力が必要になる場面が多い。
- 大人向けのタイピング練習サイトは文章が長く、漢字も多いため、子どもはむずかしくて続かない。

### 目的
- 子どもがアプリを開いてから **Space キー1回** で遊びはじめられる状態にする。
- 間違えた文字がすぐ分かり、★や「しんきろく！」で **楽しみながら** 何度も練習したくなる状態にする。
- 速さ（1分あたりの文字数）と正確さを測り、最高記録を残して上達を実感できる状態にする。

### ペルソナ
| | A：はじめてキーボードをさわる子 | B：ローマ字を習って、はやく打ちたい子 |
|---|---|---|
| 特徴 | 小学1〜3年生。ローマ字はあやふやで、キーを1つずつ探して打つ | 小学3〜6年生。学校で打ったことがある |
| 求めること | お手本を見ながら打てること、キャラクターがほめてくれること、間違えても怒られないこと | 「しんきろく！」、レベルアップ、ごほうび集め |
| 対応する Phase | MVP から | MVP から（v1.0 で本格的に） |
| 対応するモード（F-29） | 🌱 はじめて モード | 🔥 チャレンジ モード |

※ 保護者は「おうちの方へ」ページ（v1.0）で記録の確認・管理だけを行う。

### コース（追加：F-33〜F-36）
いちばん最初に、年齢に合わせたコースを選ぶ（その次にモード A/B を選ぶ）。ヘッダーのバッジからいつでも選びなおせる。

| | 🧒 子ども | 🎒 学生（中学・高校） | 💼 社会人 |
|---|---|---|---|
| アプリ名 | タイピングのもり | タイピング教室 | オフィスタイピング |
| 背景（インライン SVG） | 森（おか・木） | 教室（黒板・時計・窓・机） | 会社の社内（窓の外のビル・デスクとモニター・観葉植物） |
| 色 | 緑×黄 | 黒板の緑×木の茶 | ネイビー×グレー |
| 画面の言葉 | ひらがな中心 | 漢字かな混じり | 漢字かな混じり |
| キャラクター（F-37） | りすくん など動物5ひき | 担任の先生・校長先生・サッカー部の男子・バスケ部の女子・吹奏楽部の女子 | 上司（課長）・社長・新人の後輩・同期 |
| Lv1 / Lv2 / Lv3 | 1〜2文字 / 2〜3文字 / 4文字以上 | 学校の言葉 / 長めの言葉 / 四字熟語・ことわざ・短文 | ビジネス用語 / 長めの用語 / ビジネス文 |
| 英単語 | cat・apple など | library・science など | meeting・deadline など |
| Lv3 の長さ（平均の打鍵数） | 約 8 | 約 18 | 約 25 |
| ★3（A／B） | 30／60 文字/分 | 60／120 文字/分 | 80／150 文字/分 |

※ 最高記録・★・苦手克服用のミス集計はコースごとに分けて保存する（難しさが違うため）。シール・スタンプ・キャラクターはコース共通。

### ペルソナとモードの対応（追加：F-29〜F-32）
子ども本人が、はじめて開いたときに「どっちで あそぶ？」でモードを選ぶ（ヘッダーのバッジからいつでも選びなおせる。記録・★・シールはモード共通で残る）。

| | 🌱 はじめて モード（A） | 🔥 チャレンジ モード（B） |
|---|---|---|
| ★の基準 | ★3＝正確さ 90% 以上かつ 30 文字/分以上、★2＝75% 以上 | ★3＝正確さ 95% 以上かつ 60 文字/分以上、★2＝85% 以上 |
| 画面キーボード・ゆびガイド | いつも表示 | 最初はかくす（ボタンで出し入れ） |
| あそび中の表示 | 「のこり ◯こ」だけ（秒は出さない） | 秒と、打ちながらの速さ・正確さ |
| ミスの音 | やわらかい「ポン」 | 「ブブッ」 |
| ステージ | タイムアタックを出さない | すべて |
| きろく | ホームの最高記録 | 子ども向けの「📈 きろく」ページ（グラフつき） |

### スコープ
| 含むもの（今回：MVP、目安 1時間） | 含まないもの（今回は対象外） |
|---|---|
| ひらがなのことば＋ローマ字のお手本の表示 | 会員登録・ログイン・名前の入力（子どもの個人情報を扱わない） |
| キー入力の1文字ずつの判定（合うと緑、間違いは赤） | ステージ・効果音・シール（v1.0 で対応） |
| タイマー・のこり数・キャラクターの反応 | 画面キーボード・ローマ字のゆれ対応（v1.0 で対応） |
| 結果（★・はやさ・せいかくさ・まちがえやすかった もじ） | 英単語・ゆびガイド・とっくん（v2.0 で対応） |
| 最高記録の保存と「しんきろく！」 | みんなのランキング（サーバーと子どもの個人情報への配慮が必要なため対象外） |
| ブラウザへの自動保存 | スマホのソフトウェアキーボードでの利用 |

## 2. ユーザーストーリー

**US-01 すぐにあそぶ**（共通）
As a タイピングを練習したい子ども,
I want ボタンか Space キー1回で遊びはじめられること,
So that 迷わず、あきる前に練習が始められる.

**US-02 お手本を見ながら打つ**（A）
As a はじめてキーボードをさわる子,
I want ひらがなのことばの下にローマ字のお手本が出ること,
So that ローマ字をおぼえていなくても打てる.

**US-03 まちがいがすぐ分かる**（A）
As a はじめてキーボードをさわる子,
I want 間違えた文字が赤くなり、正しいキーを打つまで待ってくれること,
So that どこを間違えたか分かり、あわてずに打ち直せる.

**US-04 どれくらいできたか知る**（共通）
As a 1回あそび終えた子ども,
I want ★の数と、はやさ・せいかくさが表示されること,
So that 自分のがんばりが分かる.

**US-05 記録をこえたい**（B）
As a はやく打ちたい子,
I want 最高記録が保存され、こえたら「しんきろく！」が出ること,
So that もう一回やりたくなる.

**US-06 レベルアップする**（B）
As a はやく打ちたい子,
I want ステージを選び、★3 で次のステージがひらくこと,
So that 目標を持って上達できる.

**US-07 ごほうびをあつめる**（A）
As a はじめてキーボードをさわる子,
I want がんばるとシールがもらえて、ずかんで見られること,
So that 毎日続けたくなる.

**US-08 子どもの様子を見る**（保護者）
As a 子どもの保護者,
I want 練習の記録を見て、音のオン/オフやデータの削除ができること,
So that 安心して子どもに使わせられる.

- F-26：グラフは「おうちの方へ」に置き、ステージを1つ選んで直近 30 回の速さを1本の折れ線で出す（重ねると読みにくいため）。カーソルで詳細、「表で見る」で表も見られる
- F-27：スタンプは直近7日をホームに表示。今日まだ遊んでいなくても、きのうまで続いていれば れんぞく日数は切れない
- F-28：とっくんは、これまでにまちがえた文字の合計（missStats）から、その文字が多く入った Lv2・Lv3 のことば上位 20 こを選び、10 こを出す（数字キー 6）。まちがいの記録がないうちは鍵つき
※ F-29〜F-32（ペルソナ別のモード）は 2026-11-27 に追加・実装済み。モードを選ぶ前に /play を開いたときは、はじめて モードとして扱う。モードを入れる前の記録は「モード：—」と表示する
※ F-33〜F-36（コース）も 2026-11-27 に追加・実装済み。「おうちの方へ」の速さのグラフは今のコースの記録だけを表示し、練習の記録一覧にはコースの列を足した

### 補足：保存するデータ
```ts
// localStorage のキー：typing-mori（v1.0 の形。MVP の bestSpeed は Lv2 の記録として引き継ぐ）
type StageId = "lv1" | "lv2" | "lv3" | "time" | "english" | "weak";
type Mode = "a" | "b";
type Course = "kids" | "student" | "adult";
// 保存する形。best・stars・missStats はコースごとに progress の中に入れる
// （画面では「今のコースの best・stars・missStats」をとり出して使う）
type Data = {
  course: Course | null;                      // コース（null は まだ選んでいない）
  characterByCourse: Partial<Record<Course, string>>; // コースごとに選んだキャラクター（子どもは前からの character も使う）
  progress: Partial<Record<Course, {
    best: Partial<Record<StageId, number>>;     // ステージごとのさいこうきろく（文字/分）
    stars: Partial<Record<StageId, 1 | 2 | 3>>; // ステージごとのいちばん多い ★
    missStats: Record<string, number>;          // これまでにまちがえた文字と回数（苦手克服用）
  }>>;
  stickers: string[];                         // もらったシールの id（例："lv1-3"）
  sound: boolean;                             // 効果音
  history: { at: string; stage: StageId; speed: number; acc: number; stars: 1 | 2 | 3; mode?: Mode; course?: Course }[]; // 最大 100 件（全コース）
  character: string;                          // えらんだ なかま（例："risu"）
  playDays: string[];                         // 遊んだ日（例："2026-11-27"、最大 60 日）
  fingerGuide: boolean;                       // ゆびガイド
  mode: Mode | null;                          // "a"＝はじめて／"b"＝チャレンジ（null は まだ選んでいない）
  showKeyboardB: boolean;                     // チャレンジ モードで画面キーボードを出すか
};

// /play → /result への受け渡し（sessionStorage のキー：typing-mori-last）
type LastResult = {
  stage: StageId;
  correct: number;                   // 正しく打った文字数
  miss: number;                      // ミスした回数
  seconds: number;                   // かかった時間（秒）
  missChars: Record<string, number>; // ミスした文字と回数 例：{ "k": 2 }
  newRecord: boolean;                // さいこうきろくをこえたか
  prevBest: number | null;           // この回の前のさいこうきろく
  unlocked: StageId | null;          // この回でひらいたステージ
  newStickers: string[];             // この回でもらったシール
  mode: Mode;                        // 遊んだときのモード
  course: Course;                    // 遊んだときのコース
  stars: 1 | 2 | 3;                  // そのモードの基準でついた ★
};

// 出題することば（コードの中にかなだけ持ち、打ち方の候補は lib/romaji.ts で作る）
type Word = { kana: string; units: { kana: string; options: string[] }[]; display?: string; hint?: string }; // kana は打つ読み、display は漢字の表示、hint は英単語の絵文字
// 例：しか → [{ kana: "し", options: ["shi", "si", "ci"] }, { kana: "か", options: ["ka", "ca"] }]
```

## 4. 非機能要件

- **パフォーマンス**：ページ読み込み 3 秒以内。キーを押してから色が変わるまで 50ms 以内（遅れを感じない）
- **使いやすさ（子ども向け）**
  - 画面の文字はひらがなとローマ字のみ（漢字を使わない）。お手本の文字は 48px 以上
  - ボタンは大きく、マウスなしでもキーボードだけで遊べる
  - 否定的なことばを使わない（「ざんねん」→「おしい！」）
  - 点滅や激しい演出は控えめにする
- **セキュリティ・子どもの安全**
  - 認証：なし（ログイン不要）。名前などの個人情報は入力させない
  - データはこの端末のブラウザの中だけに保存し、外部には送信しない
  - 外部サイトへのリンク・広告を置かない
- **可用性**：SLA 99%（Vercel の無料プランに準じる）
- **スケーラビリティ**：データをサーバーに持たないため、同時に使う人数の制限はない
- **対応環境**：PC・タブレット＋物理キーボード。Chrome・Edge・Safari の最新版。
  - 日本語入力（IME）がオンのままでも判定できるよう、`e.key` が `"Process"` のときは `e.code`（例：`KeyA`）から文字を取る

---

## 5. 制約条件

- **予算**：無料枠で完結（Vercel Hobby プラン。データベースや外部 API は使わない）
- **期間**：MVP は目安 1 時間
- **技術**：Next.js（App Router）+ Tailwind CSS + Vercel
  - データの保存は localStorage / sessionStorage（データベースなし）
  - キャラクター・紙ふぶきは絵文字と CSS アニメーションで作る（画像素材を使わない）
- **学べること**：キーボード入力の処理（keydown）、1文字ずつの判定（文字列の index 管理）、タイマー（setInterval と経過時間の計算）
